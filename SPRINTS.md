# ExtensionSummarizer — Sprints

## Sprint 1 — Backend & AI ✅
- ASP.NET Core API structure
- Semantic Kernel + Ollama integration
- Docker Compose setup
- System prompt

## Sprint 2 — Extension Core 🔜
- Readability.js integration (clean article text extraction)
- `content.ts` implementation
- Extension → backend communication
- Basic React popup UI (loading, success, error states)

## Sprint 3 — Polish & UX 🔜
- Popup design (CSS, icon, branding)
- Error handling (backend offline, not a news page, timeout...)
- Edge cases (no text on page, article too short...)

## Sprint 4 — End-to-end & Stabilization 🔜
- Testing on various news sites (RTS, N1, B92, BBC...)
- Final prompt tuning
- `npm run build` → load in Chrome as production build

## Sprint 5 — Production *(optional)* 🔜
- Deploy backend to VPS
- Publish extension to Chrome Web Store
